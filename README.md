# Kabani Safaris client portal

The login and trip pages for Kabani Safaris clients, served at https://portal.kabanisafaris.com.

This repository holds only the web pages (HTML, CSS, JavaScript, fonts and images). No client data is stored here.
Trips are kept in a private database. A client can sign in only with an email address that has a trip, using a one-time code sent to that address.
